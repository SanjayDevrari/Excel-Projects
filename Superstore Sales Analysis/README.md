# 📊 Superstore Sales & Profitability Analysis

## 📌 Project Overview

**Superstore Sales & Profitability Analysis** is a hands-on Microsoft Excel project focused on analyzing retail sales, profitability, customer behavior, and business performance.

The goal of this project is to transform raw sales data into meaningful business insights using Excel formulas, data cleaning techniques, Pivot Tables, charts, and an interactive dashboard.

Instead of looking only at total sales, this project focuses on understanding **where the business earns profit, where it loses money, and what actions can improve overall performance.**

## 🎯 Project Objectives

* Clean and prepare raw retail sales data.
* Practice basic to advanced Excel formulas.
* Analyze sales, profit, profit margins, and discounts.
* Identify high-performing and loss-making products.
* Compare regional and category-wise performance.
* Analyze customer purchasing patterns.
* Understand monthly and yearly sales trends.
* Build Pivot Tables and Pivot Charts.
* Create an interactive Excel dashboard.
* Develop data-driven business recommendations.

## 📁 Dataset

The project uses the **Sample Superstore** retail dataset, sourced from Kaggle.

The dataset contains information about sales transactions, including:

* Order and shipping dates
* Customer details
* Product categories and sub-categories
* Sales and quantity
* Discounts and profits
* Regions, states, and cities
* Shipping modes

The original dataset will be preserved in the `data/raw/` folder. All cleaning and analysis work will be performed in the Excel workbook.

**Important:** The original dataset will not be uploaded to GitHub unless its source license and redistribution permissions allow it. The repository will include instructions for obtaining the dataset when necessary.

## 🔄 Project Workflow

### Phase 1: Setup & Data Understanding

* Download and inspect the dataset.
* Understand rows, columns, data types, and important fields.
* Import the data into Excel.
* Organize the workbook and create Excel Tables.

### Phase 2: Data Cleaning

* Inspect missing values and duplicate records.
* Identify inconsistent text and formatting.
* Check dates, numbers, and invalid values.
* Apply appropriate cleaning techniques.
* Document changes in the Cleaning_Log worksheet.

### Phase 3: Helper Columns

Create additional columns to support analysis, such as:

* Order Year
* Month Name
* Quarter
* Shipping Days
* Profit Margin %
* Profit Status
* Discount Bucket
* Order Size
* Month Start
* Weekend Indicator

### Phase 4: Master Tables & Lookup Formulas

Create supporting tables and practice:

* VLOOKUP
* HLOOKUP
* XLOOKUP
* INDEX and MATCH
* IFERROR and IFNA
* Approximate and multi-criteria lookups
* UNIQUE, SORT, and FILTER

*Formula availability depends on the Excel version being used.*

### Phase 5: Formula-Based Analysis

Use formulas to calculate and analyze:

* Total Sales and Total Profit
* Profit Margin
* Sales and Profit by Category
* Conditional totals and counts
* Top and Bottom Performing Products
* Monthly and Yearly Growth
* Running Totals
* Customer-Level Metrics
* Discount Impact
* Target Achievement

### Phase 6: Pivot Tables & Pivot Charts

Create summaries to analyze:

* Regional Performance
* Category and Sub-Category Profitability
* Monthly Sales Trends
* Discount Impact
* Top Customers
* State-Level Profitability
* Shipping Mode Performance

### Phase 7: Interactive Dashboard

Build a dashboard containing relevant KPIs and visualizations, such as:

* Total Sales
* Total Profit
* Profit Margin
* Total Orders
* Average Discount
* Loss-Making Orders
* Sales and Profit Trends
* Category and Regional Comparisons

Use charts, slicers, and timelines where appropriate to make the dashboard interactive.

Explore additional Excel features:

### Phase 9: Business Insights & Recommendations

Interpret the analysis to identify opportunities for improvement.

Recommendations will be based on actual findings from the dataset rather than assumptions.

### Phase 10: Documentation & Portfolio

* Finalize the Excel workbook.
* Export the dashboard as a PDF.
* Prepare a business insights summary.

## ❓ Key Business Questions

This project aims to answer questions such as:

1. What are the total sales, profit, and profit margin?
2. How do sales and profit change over time?
3. Which regions generate the highest and lowest profits?
4. Which product categories and sub-categories are loss-making?
5. How do discounts relate to profitability?
6. Who are the highest-value customers?
7. Which products contribute most to sales and profit?
8. Are there seasonal patterns in monthly sales?
9. How does shipping performance vary across shipping modes?
10. Which areas could offer opportunities to improve profitability?

These questions will be answered using the actual results obtained during the analysis.
