Sales Performance Dashboard
📊 Project Overview

This project is an interactive Sales Performance Dashboard created using Microsoft Excel.

The dashboard transforms raw sales data into meaningful insights using PivotTables, PivotCharts, KPIs, Slicers, and data visualization techniques.

The main objective of this project is to analyze sales performance and present important business insights through an interactive dashboard.
